# Modem KNTT – Sao chép cấu hình (PWA)

App đọc cấu hình module kết nối trung tâm (Minh Sáng) cũ và nạp sang module mới qua cáp USB‑C → RS232.

## Đưa lên GitHub Pages
1. Tạo repo mới (vd `Modem-Minh-Sang`) trong tài khoản GitHub.
2. Upload 5 file: `index.html`, `manifest.webmanifest`, `sw.js`, `icon-192.png`, `icon-512.png`.
3. Settings → Pages → Branch: `main` / root → Save.
4. Mở `https://<tên-tài-khoản>.github.io/Modem-Minh-Sang/` bằng Chrome trên Android.

## Cài lên điện thoại
Chrome → bấm nút "📲 Cài app" trên thanh tiêu đề (hoặc menu ⋮ → "Cài đặt ứng dụng"/"Thêm vào màn hình chính").
Sau đó mở từ icon như app thường, dùng được cả khi không có mạng.
